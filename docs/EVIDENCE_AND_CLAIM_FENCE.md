## Stronger claim allowed after successful deployed trace

If the deployed normal request and correction both complete successfully in one session, the submission may additionally claim that the frozen behavior was demonstrated on the deployed Strands/AgentCore runtime.

Until then, do not imply that deployed model behavior was successfully observed.

## Claim fence

Do not claim:

- production readiness
- arbitrary-user transferability
- generalized long-term companionship
- managed durable cloud recovery
- managed memory
- automatic continuation of authority after interruption
- execution where only planning occurred
- verification where only execution occurred
- successful deployed Nova behavior while the provider throttle remains unresolved

## Current limitation

The AgentCore runtime is deployed and READY. The first deployed Nova invocation returned provider throttling for daily token quota. This is preserved as an external limitation, not hidden and not routed around by changing model, region, or architecture.
